## The Microsoft Learn program

Microsoft Learn is Microsoft's free learning platform. We turn it into a shared routine: follow structured paths together, finish hands-on modules, and get help from peers when you are stuck.

- Structured Microsoft Learn learning paths
- Hands-on practical modules
- Cloud computing and Azure fundamentals
- AI and generative AI learning opportunities
- Microsoft Learn achievements and eligible certification pathways
- Practical exercises and guided learning
- Guidance for preparing for relevant Microsoft certification exams

### Know the difference before you start

### Microsoft Learn achievements

Free

Finish modules and learning paths on Microsoft Learn to earn achievements on your profile. This is free, and it is the core of this program.

### Microsoft certification exams

Separate, may cost money

A certification is a formal exam you take separately. Exam requirements and fees are set by Microsoft and can change, so check the current details on Microsoft Learn before you decide to sit one. We help you prepare; sitting an exam is your decision.

### What you gain

- Build industry-relevant technical skills.
- Earn Microsoft Learn achievements and pursue recognized certifications.
